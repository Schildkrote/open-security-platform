# Support

open-security-platform is community-supported open-source software.

## How to get help

- **Documentation:** each component's `README.md` and the aggregated [docs site](docs/index.md).
- **Issues:** open a GitHub issue for bugs or feature requests against the
  relevant component.
- **Discussions:** use GitHub Discussions (when enabled) for questions and ideas.

## Reporting security issues

See [SECURITY.md](SECURITY.md). Please report vulnerabilities privately, not via
public issues.

## Expectations

This is pre-release software. Maintainers and contributors volunteer their time;
responses are best-effort. For production use, perform independent security
review.
