# Identity

Human, machine, and agent identity security.

| Component | Lang | Description |
|---|---|---|
| `identity/oiaf` | Go | Open Identity Access Firewall: risk-based access control and adaptive MFA across Linux, Windows, RADIUS, LDAP, web/OIDC, cloud IdP, and machine identities. |
| `identity/open-pam-jit` | Go | PAM / JIT access broker: access requests, approvals, temporary credentials, encrypted secrets vault, break-glass, and session recording. |
| `identity/agent-identity` | Node/TS | Agent identity & permissions: agent registry, scoped JWT, delegation chains, JIT permissions, approvals, revocation, agent-to-agent auth. |

See each component's `README.md` and `NEXT_STEPS.md` in the repository for usage
and roadmap.
